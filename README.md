# Highland Ultra 0.3.3

修复工程文件打开与载入流程，保留正文、稳定场次关联和已有保存保护。Windows 支持从文件启动及运行期间切换工程；损坏文件明确提示，不以空文稿替代当前工程。未增加其他功能。

Mac Apple Silicon：打开 DMG，将 Highland Ultra.app 拖到“应用程序”。此公开包沿用公开 0.3.2 的应用标识，升级继续读取原有数据和设置。本机此前安装的 0.3.3 测试版原样保留；如从该本地版本改装公开版，请先保存工程，并自行重新选择偏好设置。Mac 更新使用 .app.tar.gz；普通安装优先使用 DMG。

Windows x64：运行 setup.exe，按当前用户安装；Mary 无需开发工具或 GitHub 账号。WebView2 是必要的微软运行时。旧版 0.3.2 可通过顶部“检查更新”检查、下载、验证签名，然后“保存并安装更新”。若网络连接 GitHub 失败，可下载同版本安装包手动更新；先退出正在运行的 Highland Ultra，并保留项目备份。

打开 .highlandultra 工程，或在 App 内点“打开项目”。编辑后保存，再从同一工程文件重新打开。直接启动 App 而未选择项目时会显示新文稿。

更新包强制验证签名和版本，工程与凭据不包含在安装包内。更新签名不等于 Apple 公证或 Windows 发布者证书；当前安装包没有这两种平台证书。仅公开安装包、签名、更新清单、校验值和本文档，源码保持私有。
