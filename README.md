# Highland Ultra 0.3.2

本仓库仅提供软件安装包、更新清单与版本说明。无需 GitHub 账号即可下载；开发源码继续保存在独立私人仓库。

## 本版内容

- 中文剧本编辑、场次管理、稳定批注、时停、观众反应与中文 PDF。
- 默认 DeepSeek，可选独立 OpenAI API；没有 AI 账号时可完全离线写作。
- 顶部、帮助菜单及设置中提供“检查更新”；显示版本与说明、下载进度和重试。
- 应用内更新强制验证包签名及签名绑定的版本，保存失败或文件冲突时停止安装。

## 安装与更新

Mac Apple Silicon：下载 DMG，将应用放在独立文件夹，保留旧版。
Windows x64：运行 setup.exe，按当前用户安装；缺少 WebView2 时由微软引导程序安装。
更新时在应用中选择“检查更新”，下载验证通过后选择“保存并安装更新”。Windows 安装会退出应用，Mac 安装后请重新打开。

更新包签名与 Apple 公证、Windows 发布者证书不同：首次安装文件尚无上述系统证书，系统可能提示未知开发者。Windows 已在 Runner 编译及测试，尚未完成真实电脑界面验收。

本版不含多轮 AI 聊天、长期记忆、ChatGPT 登录或云协作。更新仅替换应用，项目与设置在本机保留；请持续保留项目备份。

Highland Ultra 是独立个人项目，与 Highland Pro / Quote-Unquote Apps 无关联。
